題目、寫作、回顧，不必散在不同地方。

01

練正在學的內容

貼上自己的題目，或讓 ChatGPT 依你的要求產生題包，再匯入練習。多題也能分配入門、進階與挑戰的題數。

02

讓公式寫得順手

使用 LaTeX 公式預覽、指令與環境補全、常用符號快捷插入，專心把定義、計算與證明寫清楚。

03

把修正留下來

保留提交歷程，將作答交給 ChatGPT 檢查，再匯入報告、回到原文修正。最後把成果匯出成 LaTeX 與練習資料。

進入練習工作台 ↗
  1. 準備題目貼上題面，或跟著指引取得 ChatGPT 題包。
  2. 寫下自己的解法確認題面，開始作答，需要時逐級查看提示。
  3. 檢查、修正、帶走回顧作答歷程，離開前匯出想保留的內容。
需要 ChatGPT API 金鑰嗎？

不需要在 MathForge 填入 API 金鑰。出題與檢查採用手動往返：複製要求到你自己的 ChatGPT，再把 JSON 題包或報告匯入。你也可以只貼自己的題目來練習；缺少提示或解答不會阻擋作答。

資料保存與 Sites 入口

免登入練習請在重新整理或離開前匯出資料。雲端保存目前需獲授權的帳號。另有 MathForge · ChatGPT Sites 入口，目前需存取授權；第一次體驗建議使用上方的公開網頁版。
